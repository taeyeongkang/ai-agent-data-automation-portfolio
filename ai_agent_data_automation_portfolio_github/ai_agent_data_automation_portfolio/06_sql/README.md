# Oracle SQL Practice

교육과정에서 작성한 SQL 실습 중 개인 연습 스크립트만 선별했습니다. 교재 예제 파일(`scott.sql`, 예제코드)은 포트폴리오 증거에서 제외했습니다.

주요 내용:

- 문자열/형변환/CASE
- 다중 테이블 JOIN
- `SUM`, `AVG`, `MAX`, `MIN`, `GROUP BY`
- Subquery / CTE
- `LAG`를 이용한 기간 비교
- 조건 분류

`script_07.sql`은 CTE와 `LAG`를 활용한 기간 비교 실습입니다. 원문의 데이터 의미·연속월 보장에는 검토 과제가 있어 예측모델 성과로 해석하지 않습니다.
