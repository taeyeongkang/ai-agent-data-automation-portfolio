# 진행 중 파이널 프로젝트 — 서울 상권 분기별 지표 비교 자동화

**Status: In Progress**

선택한 상권·업종의 점포 수, 개업 수, 폐업 수, 폐업률 등을 분기별 비교표로 정리하는 작업을 자동화하는 프로젝트입니다.

현재까지의 초점:

- 기존 서비스 조회값과 공식 원자료 대조
- 일반/전체 점포 수 등 지표 정의 확인
- 상권·업종·분기 단위의 비교 구조 설계
- 출처·기준분기, 누락·중복 검증 계획

다음 단계:

1. 동일 상권·업종·분기의 비교표 생성
2. 누락/중복 및 원자료 대조
3. 작업시간과 자동화 효과 측정
4. 구현 결과에 따른 범위 조정

현재 구현이 진행 중이므로 완료된 시스템이나 정량 성과를 주장하지 않습니다.
