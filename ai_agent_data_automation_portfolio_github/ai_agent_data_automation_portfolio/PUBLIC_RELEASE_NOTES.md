# 공개용 정리 내역

이 ZIP은 GitHub 공개를 전제로 원본 학습 폴더에서 포트폴리오 가치가 높은 파일만 선별한 사본입니다.

## 제거/치환

- `.env`와 로컬 환경 폴더
- 하드코딩된 OpenAI/API key
- Dify export의 API credential
- Gmail 주소와 Make connection ID
- Google Spreadsheet ID
- 로컬 절대경로
- `__pycache__`, `.ipynb_checkpoints`
- 개인정보 가능성이 있는 메일/Sheets/Zapier 캡처와 보고서 원본

## 포함하지 않은 이유

교육자료 전체를 그대로 공개하기보다 **본인이 구현·수정·실행한 대표 산출물** 중심으로 구성했습니다. 공개 권한이 불명확한 원자료와 단순 교재 예제는 제외했습니다.
